# SuperMartijn642's Core Lib — GUI Framework

[![Download Latest](https://img.shields.io/github/v/release/ServantPlait/supermartijn-core-lib-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/ServantPlait/supermartijn-core-lib-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

A shared library providing GUI elements, configs, and utilities for SuperMartijn642's Minecraft mods.

![SuperMartijn642's Core Lib — GUI Framework Preview](https://cdn.modrinth.com/data/rOUBggPv/e745e719d7fe2aa0335d819ca9c97defbf2e0bcb_96.webp)

## Features

- Clean GUI widget system for custom screen creation
- Config system with in-game GUI screen support
- Block entity and tile utility helper classes
- Required by RF Lamps, Efficient Quarry, and more
- Extensive JavaDoc for mod author integration

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
